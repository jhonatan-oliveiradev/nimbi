NX Studio · Nimbi Desktop Companion

Privacy Policy

Nimbi Desktop Companion is designed as a local desktop companion. This policy explains what information the current version of Nimbi accesses, how that information is used, and the choices available to users.

Effective date: October 2, 2026 · Publisher: NX Studio

1. Information Nimbi accesses

The current version of Nimbi may access local application and system state that is necessary to provide its desktop-companion functionality. This includes local state exposed by the RunOptic service running on the same device, window and display geometry, pointer interaction state, and locally stored Nimbi preferences.

2. How information is used

Information accessed by Nimbi is used to render the companion, reflect local agent activity, manage window placement and presence, and maintain user preferences such as placement and opacity.

3. Data transmission and analytics

This version of Nimbi does not operate an NX Studio analytics service, advertising service, or user-account backend. Nimbi does not sell personal information.

Communication with RunOptic occurs locally on the user's device. Nimbi does not intentionally transmit RunOptic telemetry, prompts, responses, or local interaction data to NX Studio servers.

4. Data storage

Nimbi stores only the local preferences required for the application experience, such as companion placement and presence settings. These preferences remain on the user's device unless the operating system or the user separately backs them up.

5. Personal information

The current version of Nimbi does not require a Nimbi account and does not intentionally collect a user's name, email address, precise location, contacts, payment information, or advertising identifiers.

6. Third-party and local services

Nimbi can display state received from locally running software such as RunOptic. Those applications or services may have their own privacy practices. This policy covers Nimbi Desktop Companion itself and does not replace the privacy terms of third-party software a user separately chooses to run.

7. Children

Nimbi is not designed to knowingly collect personal information from children. The current application does not provide account creation or targeted advertising.

8. Future features

If future versions add cloud-connected AI, voice processing, account features, analytics, or other functionality that changes how information is processed or transmitted, this policy will be updated before or alongside those features.

9. Your choices

Users can stop Nimbi at any time from the system tray. Local Nimbi preferences can be removed by uninstalling the application and deleting its local application data.

10. Contact

Questions about this policy or Nimbi can be submitted through the project's public support channel: GitHub Issues.

This policy applies to the current Microsoft Store submission of Nimbi Desktop Companion.
